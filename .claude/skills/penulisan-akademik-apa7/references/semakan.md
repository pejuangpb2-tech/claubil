# Senarai semak APA 7 / APA 7 checklist

Run every item before returning a document. Report anything that fails or cannot be verified.

## Sumber / Sources
- [ ] Every in-text citation has a matching reference entry with the same spelling and year; every entry is cited in the text.
- [ ] Personal communications are cited in the text only.
- [ ] Nothing was invented: missing details are marked `[perlu disemak: ...]` / `[to verify: ...]`.
- [ ] Direct quotations carry a page or paragraph number; quotations of 40+ words are block quotations.
- [ ] Secondary sources use "as cited in" / "seperti yang dipetik dalam", and only the source actually read is listed.

## Sitasi dalam teks / In-text
- [ ] "&" inside parentheses, "and" / "dan" in running text.
- [ ] Three or more authors use "et al." (or the institution's "dkk.") from the first citation.
- [ ] Group-author abbreviations are defined at the first citation and used afterwards.
- [ ] Multiple citations in one parenthesis are alphabetical and separated by semicolons.

## Senarai rujukan / Reference list
- [ ] Heading "References" / "Rujukan", centred, bold, new page.
- [ ] Alphabetical order; double-spaced; 0.5 in (1.27 cm) hanging indent.
- [ ] Sentence case for article, chapter and book titles; journal names in Title Case; italics on book titles, journal names and volume numbers.
- [ ] Issue numbers in parentheses after the volume, page ranges with an en dash (45–60).
- [ ] DOIs as https://doi.org/...; no publisher location; no "Retrieved from" without a retrieval date.
- [ ] Malay names written consistently (full name, not inverted) and Chinese names surname first.

## Format
- [ ] 1 in / 2.54 cm margins; an accepted font; double spacing; 0.5 in paragraph indent; page numbers top right.
- [ ] Headings follow levels 1–5 with no skipped levels; no "Introduction" heading under the title.
- [ ] Tables and figures numbered in order, bold label above, italic title, *Note.* below, and each mentioned in the text first.
- [ ] One language for labels throughout (English or Malay set), applied consistently.

## Bahasa / Language
- [ ] Formal academic register; no colloquialisms.
- [ ] Numbers: words below 10, numerals from 10 and for statistics and measurements.
- [ ] Malay text follows DBP spelling and grammar (di/di-, daripada/dari, ialah/adalah).
- [ ] Bias-free wording.
